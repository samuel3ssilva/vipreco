# Matriz de prontidão — Gate R0

**Onda/trilha:** preparação do Gate R0 (`PLANO-MESTRE.md` §10 e §17.5), Onda 5 continua
**bloqueada**. Este documento não é um pedido de aprovação nem uma autoavaliação de
"pronto" — é a matriz objetiva que o Founder/PMO usa para decidir se o Gate R0 abre.
Nenhuma linha desta matriz, por si só, libera dado real, piloto, deploy, DNS, custo ou
credencial nova.

**Autoria:** CTO (este agente), preparação documental autorizada por
`PLANO-MESTRE.md` §17.5 ("o CTO está autorizado a preparar a documentação... em PRs
pequenos e revisáveis, sem mergeá-los e sem que isso constitua autorização da Onda 5").
**Este PR não é mergeado sem autorização humana específica**, conforme
`PLANO-MESTRE.md` §1 "Regras imediatas".

## O que este documento não é

- **Não é uma aprovação do Gate R0.** Nenhuma linha desta matriz, isoladamente ou em
  conjunto, autoriza dado real, piloto, deploy, DNS, custo ou credencial nova.
- **Não é uma autoavaliação otimista.** Os itens marcados como "documento de trabalho"
  não existem neste worktree — são referenciados pelo nome esperado porque estão sendo
  preparados em branches paralelas independentes nesta mesma rodada, por mandato
  distinto. Este CTO não leu o conteúdo desses arquivos e não pode atestar sua
  qualidade, apenas registrar que a preparação foi mandatada.
- **Não substitui o checkpoint humano único** que `PLANO-MESTRE.md` §17.7 exige ao final
  da preparação do Gate R0. Esta matriz é um dos insumos desse checkpoint, não o
  checkpoint em si.

## Como usar esta matriz

O Founder/PMO decide, item a item, se o "estado atual" descrito é suficiente ou se a
"lacuna" precisa ser fechada antes do Gate R0. Para os itens 6–13, a decisão real só é
possível depois que os documentos de trabalho referenciados forem integrados e lidos —
esta matriz não pode ser a única fonte para aprovar esses itens. Os itens 14 e 15 nunca
podem ser considerados satisfeitos por este documento, por nenhum outro documento técnico,
nem por qualquer CTO ou agente de IA — são, por desenho, os únicos dois itens que só um
ser humano pode fechar.
